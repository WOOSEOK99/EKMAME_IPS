# EKMAME / EKGUI 웹 사용설명서

0.289.3~0.289.8 배포 글과 화면을 바탕으로 정리한 한국어 가이드입니다.

**[웹 사용설명서 열기](./index.html)**

GitHub Pages가 저장소의 `main` 브랜치 **루트(`/`)**를 게시하는 경우 사이트 경로는 다음과 같습니다.

`https://wooseok99.github.io/EKMAME_IPS/guide/`

## 구성

- `index.html` — 기능별 설명과 출처 링크
- `style.css` — PC·모바일 반응형 디자인
- `app.js` — 목차 검색, 모바일 메뉴, 스크린샷 확대
- `images/` — 사용자가 제공한 PDF에서 추출한 EKGUI 실제 화면 이미지

## 문서 범위 및 주의사항

- 0.289.3~0.289.8에 추가·개선된 기능을 중심으로 작성했습니다.
- 실제 실행 파일을 구동해 재검증한 문서는 아닙니다.
- 0.289.7에서 배포 폴더 구조가 변경됐으므로 구버전 사용자는 데이터 백업 및 직접 이전이 필요합니다.
- ROM/CHD 파일과 게임 실행 파일은 이 설명서에서 배포하지 않습니다.

## 0.289.9 추가 안내 (2026-10-29)

기존 0.289.3~0.289.8 사용설명서의 내용과 목차를 유지하면서, 아래 변경 사항을 [웹 설명서](./index.html)의 해당 항목 아래에 추가했습니다.

- **처음 사용하기:** 도움말(H)에 IPS 패치파일 다운, MNG 파일 다운, 롬파일 다운, 사용 설명서 항목 추가
- **게임 목록과 검색:** 게임명·ROM name으로 외부 사이트의 ROM 검색 결과 확인 및 선택 게임 우클릭 다운로드 연동. ROM 파일 자체는 프로그램에서 배포·공유하지 않음
- **ROM 검사:** 다운로드한 파일은 ROM 폴더로 직접 이동하고 게임 우클릭 → 검사로 Passed 상태 확인. 검색 단계·진행률 표시 및 응답성 개선
- **IPS 패치:** 원더보이, KOF, CPS1/CPS2, 사이쿄 등의 한국어 패치 게임 지원 및 호환성 개선
- **화면과 비디오:** 창·전체화면 및 화면비 설정 간소화, Model 3 GPU 설정 안내, Crisis Zone·Time Crisis II 일부 버전의 System 23 GPU 가속 추가
- **아트워크·동영상:** MNG 영상의 MP3 오디오 지원 및 미디어 경로 설정 개선
- **문제 해결 및 변경 이력:** 클론 게임에 치트 파일이 없으면 부모 게임의 파일을 자동으로 불러오는 기능
